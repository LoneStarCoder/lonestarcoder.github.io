# WSUS - Update IIS Timeout
*Author: Brody Kilpatrick* | *Created: May 11, 2021*

**If WSUS keeps timing out, you may need to update the timeout on the IIS Site to something longer.**

Go to IIS Manager

WSUS Administration

Advanced Settings

Limits

Connection Time-out

Set it from 180 to 3600
