# SCSM Tokens
*Author: Brody Kilpatrick* | *Created: October 25, 2011*

[me]  
[mygroups]  
  
[now] +|- # s|m|h|d  
  
where:  
  
s => seconds  
m => minutes  
h => hours  
d => days  
  
for example:  
[now] + 2 h is now + 2 hours  
[now ]+ 3 m is now + 3 minutes  
[now] - 2 h is now - 2 hours
